# Deployment Guide - FX-Lab

## Quick Deploy to GitHub Pages

### Step 1: Push to GitHub
```bash
git init
git add .
git commit -m "Initial commit: FX-Lab v0.5.0"
git branch -M main
git remote add origin https://github.com/yourusername/fx-lab.git
git push -u origin main
```

### Step 2: Enable GitHub Pages
1. Go to repository Settings
2. Scroll to "Pages" section
3. Select "Deploy from a branch"
4. Choose branch: `main`
5. Choose folder: `/ (root)`
6. Click Save

### Step 3: Update README Links
1. Replace `yourusername` in README.md with your actual username
2. Update any demo URLs to your GitHub Pages URL
3. Commit the changes:
```bash
git add README.md
git commit -m "Update links to production URLs"
git push
```

## Custom Domain (Optional)
1. Add CNAME file with your domain:
```bash
echo "your-domain.com" > CNAME
git add CNAME
git commit -m "Add custom domain"
git push
```
2. Configure DNS records with your domain provider
